# Status

Existence of an odd perfect number remains open.

Formalized constraints:
- Euler form
- Cyclotomic divisibility lemma (order argument)
- Steuerwald 1937 (ordinary exponents all exactly 2)

Equal-exponent cases \(3 \le r \le 83\) are verified in the external mathdiscoveries library.

Remaining local gaps are elementary and finite (explicit factor chain and ZMod order expansion).
